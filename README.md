# 秋遊特務

Next.js App Router、TypeScript、Firebase Authentication 與 Realtime Database 的秋遊方案投票網站。已移除 OpenAI hosting 設定，可部署至一般 Next.js 主機。

## 本機啟動

Node.js 20.9 以上。複製 `.env.example` 為 `.env.local`，填入 Firebase 網頁應用程式設定。

```sh
npm install
npm run dev -- --port 3008
```

首頁：http://127.0.0.1:3008/

方案後台：http://127.0.0.1:3008/admin

Firebase Google 登入提供者須啟用，Auth 授權網域須包含實際使用的網域。環境變數的 `databaseURL` 要使用純 HTTPS URL。更改環境變數後需重啟開發服務；正式部署需重新建置。

## 使用流程

同事先比較預設展開的大卡片，也能在偏好區直接切換方案，選擇午餐／按摩／下午茶後再以 Google 登入並確認送出。切換陣營保留各方案的偏好與專屬備註草稿，登入也保留尚未送出的選擇。選配、投票摘要及送出確認繼承 A 黃色／B 粉色，並標示方案代號與派別。

主方案與每組選配都能使用跑燈抽籤：從該組實際選項等機率抽選，在選項間快速切換、逐漸減速並落定，只更新草稿，不自動送票。使用 crypto.getRandomValues 搭配拒絕取樣消除餘數偏差，不排除連續抽中相同選項。

跑燈短音與最後和弦由 Web Audio 產生，音效排程及畫面共用同一拍點表，優先以音訊輸出時鐘對齊；手動選擇、切換方案、離開頁面、開啟片頭或開始另一組抽籤會取消舊動畫與音效。減少動態設定直接顯示結果；音效無法啟用時仍可完成抽選。

投票可填是否攜帶家眷、家眷總人數（不含本人）及家眷備註。資料存於 voteDetails，投票確認、本人回填與主辦明細都能顯示；家眷不增加公開票數。主辦可看家眷人數及同行合計，舊票未填欄位會明確標示。每個 UID 儲存一票，開放期間可修改。菜單圖片可點開放大。

戰況不需登入即可訂閱 Realtime Database：票數、支持比例、姓名與重疊頭像即時更新。桌面上兩張戰況卡依票數比例平滑調整寬度，範圍為 30–70%，避免少數方內容消失；平手及零票各半，手機維持直排。頭像 hover／鍵盤聚焦／點選顯示姓名。戰況卡滑入視窗時播放登場與 VS 撞擊，邊框流光與背景掃光持續運作，支持度維持原本分段色條，票數變更時跳數與亮框；離開視窗或切到背景分頁時暫停，減少動態設定停用裝飾動畫。主辦入口為方框按鈕，只在管理員登入後顯示。

大卡片中央 VS 在滑入視窗內側時播放紅藍衝線、撞擊回彈與擴散框，完全離開畫面才重置，再次滑入可重播。登入、資料同步及儲存共用方塊跑燈；方案與主辦後台使用 A／B 小卡對決載入面板。方案載入時保留卡片位置，戰況以票數及頭像佔位顯示等待，收到資料立即切換，不額外延長 loading；減少動態效果設定會停用非必要動畫。

首次以管理員登入後，至後台按「建立原始方案」，再編輯活動資訊、方案、選配及截止時間。後台可手動關閉投票，儲存後前台即時更新；同時編輯時以版本檢查避免覆蓋他人的變更。

登入會寫入 `users/{uid}`。下列兩個 Email 自動設為 admin：

- egroup.shelly@gmail.com
- egroup.carol@gmail.com

其餘使用者預設 member。每次登入前先提示使用 Email 以 `egroup.` 開頭的 Google 帳號（例如 egroup.xxx@gmail.com）；這類帳號可直接投票。其他帳號登入後會列入待審核，由主辦人在「帳號與審核」通過或不通過。通過後投票頁即時開放，重新登入保留審核結果；審核綁定當時的 Email，Email 改變需重新判斷。現有投票不會因新增資格流程而被刪除。依本案內部使用需求，管理員及投票資格採前端判斷，未部署自訂資料庫規則。Firebase 控制台現有存取規則仍由專案方管理；前端角色判斷不等於資料庫存取控制。

主辦「帳號與審核」顯示註冊總人數、待審核、可投票與已投票人數；可用姓名或 Email 搜尋，包含尚未投票的帳號。

餐廳／按摩選項維持 ID 關聯；已有投票的選項及題目不能直接移除。修改名稱、時長、說明、價格或安排方式時，儲存前會列出前後內容與受影響名單供確認。新選項使用新的 UUID，不重用刪除的 ID。

## 資料位置

- `users/{uid}`：Email、顯示名稱、頭像、角色、建立及更新時間；人工審核存於 `voteReview`（status、email、reviewedBy、reviewedAt）。未審核與公司帳號資格由 Email 和審核紀錄判斷，不另存重複狀態。
- `outing/catalog`：活動設定、方案、版本與截止時間（投票 `settings.closesAt`；接受任務 `settings.acceptClosesAt`，0 或沒有就是不設截止）。
- `outing/votes/{uid}`：投票方案、姓名、Google 頭像及更新時間。
- `outing/voteDetails/{uid}`：選配與備註；一般頁面只顯示本人，後台顯示投票明細。首頁「接受任務」登記的備註與家眷也存在這裡。
- `outing/teams`：分隊結果 `{uid: "red" | "blue"}`，由主辦在後台「分隊」儲存，或由首頁分隊面板的選人與抽籤寫入。
- `outing/teamConfig`：分隊設定（是否公開、隊長選人、輪流、誰先選、兩位隊長）。
- `outing/declines/{uid}`：說「本探員另有要務」的人 `{displayName, photoURL, at}`；再接受任務就移除。
- `outing/teamDraw`：最後一次抽籤 `{seq, uid, team}` 或 `{seq, all: true}`，每個開著首頁的人據此播放同一場抽籤動畫。

## 開場

行程為熱血對戰派（六度空間雷射對戰＋飯店下午茶）。網站載入時先是黑色主控台開機畫面（`components/outing-loading.tsx`）：《秋遊特務》字樣、特務持續朝「特」開槍的紅點、掃描光條與「ESTABLISHING SECURE LINK」，純 CSS，腳本還沒載入就會動。

開場是一支 47 秒、當成大銀幕上映預告來做的《秋遊特務》，一支片一口氣到底：全片沒有黑幕、沒有靜音、中途不換歌，007 開場，不可能的任務從交棒處一路推到結尾，最後收在它招牌的「燈燈」兩下重擊上點燃自毀。每個切點都落在音樂的拍子上，片中只有兩位老闆，沒有其他 AI 人物：
- **007**：白點、槍管、轉身開槍（樂團在槍響進來）、紅色流下、剪影片名卡「今年秋天／兩位老闆／一個戰場／只有一隊能贏」隨和弦換卡（剪影完整入鏡、不切到頭）；
- **交棒（由弱漸強）**：007 最後一個重音上，最後一張卡兩人之間的雷射線像導火線一樣從兩端點燃，慢慢燒向中間（約 3.5 秒）；鏡頭往燃燒點推近、剪影與字沉進黑暗，007 重音後的長和弦完整響完、在它下一句之前收住，餘音（殘響）再延續約兩秒，不可能的任務的手鼓從很小聲一路推上來，兩端燒到中間的那一拍正好是它的貝斯進來——畫面一閃，就是地上點燃的導火線；
- **不可能的任務**：導火線一路燒過地面，「任務簡報」；機密檔案夾（蓋「機密」章的 FILE 01 RED LEADER／FILE 02 BLUE LEADER，兩位隊長的照片落在檔案上、代號、塗黑的機密行），「你的任務——」「10.29 攻佔六度空間」；火燒的邊緣掃進場地，快剪場地／兩位隊長集合／下午茶，紅不讓開槍、刀槍Blue回擊，兩人**對決**：橫式同框互瞄、直式紅藍特寫交叉剪，重拍上兩道雷射在畫面中央對撞爆開（衝擊環、紅藍火花、變形鏡頭光暈）；金庫雷射網、鎖定兩位隊長，紅隊隊長前滾翻起身單膝開槍（落在曲子最強的重拍）、藍隊隊長跪地滑行開槍（水花一路飛濺），畫面中央逐字打出「SHOULD YOU CHOOSE TO ACCEPT IT／如果你選擇接受……」，畫面下緣的導火線一路燒著；
- **片尾**（同一首曲子繼續推進、音量全片最高）：導火線燒到盡頭，片名「秋遊特務」在場地裡隨重擊爆出、答了那句「如果你選擇接受……」（音樂在前一刻吸一口氣），衝擊環與火花炸開，「遊」裡的特務朝「特」開槍再舉起手槍；下一個重拍日期像電影上映日期卡一樣砸下（「10.29 THU」，下面是「12:00・六度空間 LAZERTREKS」），下緣出現電影海報式的演職員表；經典台詞「一如往常，若你被雷射擊中，主辦單位將否認知情。」打出（「主辦單位將否認知情」為橘黃色，網站簡報裡的同一句也是），停留到不可能的任務的主旋律再回來（片名再閃一次光）；接著「本訊息將自動銷毀」砸進台詞的位置，旁邊紅色數字 5、4、3、2、1 每兩拍一個（約一秒）倒數，每一數畫面邊緣紅色警報、畫面抖動、嗶聲；旋律那一句唱完，倒數停在 1，不可能的任務的「燈燈」兩下重擊落下（數字跟著跳、警報閃兩次），「燈燈」完才歸零：音樂停下的那一拍點火爆炸（全片最響）、爆白，畫面從字幕處起火燒穿，接到主頁。

橫式為 2.39:1 遮幅，手機直式另有重新構圖的版本。

預告片是預先算好的影片（`public/assets/trailer/trailer-16x9.mp4`、`trailer-9x16.mp4`），網站依螢幕方向播放其中一支，畫面上再疊即時底片顆粒。進站先顯示預告海報封面（橫式與直式海報各一張），點「播放預告」才有聲播放（封面寫的長度由 `TRAILER_BURN_AT` 算出，換片不必再改字）；瀏覽器擋下時提示再點一次，影片無法播放時可直接跳過。

**接到主頁的轉場**：影片播到自毀那一刻（`TRAILER_BURN_AT`），畫面凍結成畫布，由網站即時燒穿（`lib/film-burn.ts`：雜訊場擴散的焦痕、白熱火邊、火花、餘燼與煙），主頁就在底下從燒出的洞裡出現，配樂照常播完；主視覺的 logo 同時被雷射刻出。按「跳過預告」（或 Esc）也是同樣的燒穿，只是更快；在封面就跳過時，封面海報燒掉。減少動態效果時直接切換。首頁的「重播預告」會回到頁首並直接開始播放。

首頁主視覺（`components/mission-hero.tsx`、`app/mission-hero.css`）與頂端導覽列沿用預告片風格（導覽列右邊是「探員登入」，登入後是頭貼與帳號選單，接受任務後頭貼才戴上探員紳士帽，`components/account-menu.tsx`、`components/agent-hat.tsx`）：黑底電影海報、兩位老闆持雷射槍的主視覺照、雷射紅藍光、取景框。字樣 `components/title-mark.tsx`（樣式 `app/title-mark.css`，字形輪廓 `lib/title-mark-paths.ts`）：Noto Serif TC Black 的鉻金屬字，巧思做在字裡——「遊」右下的「子」換成鋼灰色的特務剪影，鉻色輪廓線讓它在小尺寸也清楚：完成的字樣是他把手槍舉在臉旁、槍口亮著紅光（`public/assets/brand/agent.svg`），「特」字寸的那一點是他雷射留下的紅點；紅藍輪廓光呼應兩隊。`motion="intro"` 時像 007 開場：四個白點滑入、像光圈一樣打開成字，特務先伸直手臂瞄準「特」（`agent-aim.svg`，兩個姿勢同一個人、同一個座標）開槍，雷射落在「特」上留下紅點，接著才把槍舉起來；`motion="scan"`（載入畫面）反覆瞄準、開槍、舉槍。字形輪廓由字型轉出並合併重疊筆畫（字裡不會有接縫線），不再依賴字型載入；剪影與輪廓由 scratchpad 的 `traceagent2.cjs`、`buildmark2.cjs` 產生。字形輪廓由字型轉出，不再依賴字型載入。左側列出集合時間、地點與戰後下午茶，集合時間與地址讀取方案 B 行程的第一站。

## 行程頁

首頁只放這次要去玩的內容，投票、方案比較與戰況都已拿掉（後台 /admin 仍可用）。主視覺下方是不可能的任務風格的電腦終端機畫面（`components/mission-sections.tsx`、`app/mission-page.css`）。進場動畫每次捲回來都會重播（`components/use-in-view.ts`：完全離開畫面後再進來就從頭播放，包括字樣、隊長對決、守則、接受任務的簡報與導火線）：

- **01 任務流程**：開機字幕逐字打出（每行之間停一拍），STATUS 依登入的人是否已接受任務顯示「等待特務接受」或綠色的「ACCEPTED」；倒數五秒「本訊息將自動銷毀」、主控台警報、畫面故障、點火燒穿（`components/mission-briefing.tsx`），留下「訊息已銷毀」三十秒後才重新傳送；捲走再回來就馬上重新傳送。減少動態效果時不倒數、不燒。下面是方案 B 的行程紀錄（下午茶一行直接寫出最高票的飯店），右上角是任務倒數鐘：天／時／分／秒四格翻牌數字、閃爍的冒號、集合時間與地點，剩不到一天轉紅並脈動；最後一行「你的任務，如果你選擇接受——」接到下一段：一條導火線從這行往下燒到「02 接受任務」，隨捲動燃燒，燒到時接受任務區點亮。
- **02 接受任務**：不可能的任務式的機密簡報（`components/mission-accept.tsx`）——「早安／午安／晚安，○○ 特務。你的任務，如果你選擇接受……」逐字打出；點指紋掃描器以公司 Google 帳號驗證身分，填注意事項與行動編制（單獨行動／攜帶家眷、人數、家眷備註），再「按住指紋」直到圓環走完就接受任務。接受後播放完成動畫：綠色掃描線打開特務檔案、鎖定框套上照片、資料逐行進來、MISSION ACCEPTED 印章重重蓋下（卡片震動、墨點飛濺、衝擊波）、打出「身分確認・任務已接受」，簡報倒數三秒後自己燒掉，名單裡自己那格亮起；燒掉後可按「◀◀ 調閱備份」重看：灰燼像錄影帶倒帶一樣回到簡報（REWIND 字幕、雜訊條）、重新逐字播放，看完照慣例再自毀一次。這裡沒有登出鈕（登出在右上角帳號選單）；不能來的人按「本探員另有要務」，再確認一次（「雷射槍跟下午茶 buffet 都會很想你」）後檔案轉入潛伏：照片蓋黑條、行蹤塗黑、蓋上「潛伏中・DORMANT」、打出「收到。這次任務你不在場——主辦單位將否認知情。」，簡報一樣自毀；他會從名單、分隊與抽籤中移除（`votes` 與 `teams` 刪掉，`voteDetails` 保留），另記一筆 `outing/declines`，主辦在「帳號與審核」看到「不參加（另有要務）」；任務流程的 STATUS 顯示「DORMANT・另有要務」。隨時可以「改變心意，歸隊」，資料還在，按住指紋就回到名單。資料寫進原本的 `votes`／`voteDetails`（方案 B），所以沒投過票的人也能登記、主辦明細照常看得到；投票關閉後仍可登記，資格審核規則不變。主辦可在後台「編輯方案 → 活動、投票與接受任務」設定**接受任務截止時間**（台北時間，可留白）：設了之後，標題右邊出現同款倒數鐘（DEADLINE・接受任務截止，剩不到一天轉紅並脈動，下面寫截止時間），頂端導覽列日期旁也有紅框倒數「接受任務 ○天○時○分○秒」（最後一天整個轉紅；手機上取代日期、不顯示秒），跑馬燈多一則「接受任務截止還有…」；時間一到就停止接受：還沒回覆的人看到「接受任務已截止」（請聯絡主辦人），已接受與潛伏的檔案照常顯示、但不能再修改、婉拒或歸隊，倒數鐘換成 ACCEPTANCE CLOSED、終端機狀態轉橘，頁首倒數與跑馬燈那則收起；送出時也會再檢查一次截止時間（以伺服器時間為準）。右側是已接受任務的特務檔案照名單（每張照片都戴探員帽），分好隊後依紅隊／藍隊／待分隊顯示；資料庫連不上時會直接說明，不會一直轉圈。
- **03 作戰場地**：六度空間的監視器畫面（即時時間戳），裡面藏了彩蛋——兩位隊長輪流出現：從左右大柱後探身、從油桶掩體後冒出上半身、站在走廊遠處，或從前景走過；每一輪兩人都會在每個位置各出現一次（所以兩人都會走過畫面），順序隨機、不連續同一位置。滑鼠游標本身就是準心（系統游標圖，滑鼠在哪準心就在哪、不會延遲），對準隊長時換成收緊的紅色準心；畫面中間不再有固定準心；手機點下去的地方會跳出準心。點一下就開槍，命中有白閃、火花與 HIT +1，依出場方式倒下，右下角計分（`components/recon-targets.tsx`）；開槍有雷射槍聲、沒打中會在迷宮裡跳彈「叮」一聲，打中時背心爆電，紅隊隊長大叫、藍隊隊長尖叫（合成人聲，不放錄音檔；`lib/recon-sound.ts`，和抽籤音效共用 `lib/sfx-core.ts`）。接著是場地情報、兩位隊長的對決海報（`components/captains-faceoff.tsx`：紅藍兩半斜向雷射接縫、兩人舉槍互瞄、光束在 VS 後方對撞、鎖定框）、任務模式、捷運步行路線（手機改用較高的直版路線圖，字維持正常大小），以及六度空間的 Google 評論。場地說明、任務模式、交通與須知整理自六度空間官網（`lib/mission-brief.ts`）。

後台「分隊」分頁（`components/admin-teams.tsx`、規則在 `lib/teams.ts`，設定存在 `outing/teamConfig`）分四個步驟，最上面一行隨時顯示「首頁現在」看到什麼：

2. **分隊方式**：「主辦分隊」（在下方隊伍名單手動指定，或「隨機分配其餘的人」／「全部重新抽籤」，隊長不動，再「儲存分隊」寫入 `outing/teams`），或「隊長選人」（兩位隊長在首頁挑人）。隊長選人可設定「輪流選」（預設開：從先選的隊伍開始一隊選一個；誰先選可「抽籤決定」或直接指定紅隊／藍隊先選；人數單數時，先選的隊伍也多選一位）或不輪流（隨時可選）。
3. **公開到首頁**：「前台顯示分隊」預設關，關閉時首頁完全不顯示分隊資訊；可以先把隊長和方式準備好再公開。

首頁在「接受任務」下方顯示 TEAM_DRAFT 分隊面板（`components/team-board.tsx`，公開後才出現），排成像隊長對決海報：紅藍兩半與雷射接縫、記分板與鉻金屬 VS；隊長輪流選人時，下面是 FIRST PICK 抽籤：選擇燈在紅隊／藍隊之間跳、越跳越慢，停在先選的隊伍並亮起隊色（人數單數時註明由它多選一位）。兩側各是一整隊：隊長的大格在外側（還沒登入的隊長由特務剪影待命），選進來的人排在旁邊、空位是待命的剪影；中間是待分隊的特務檔案卡。輪到的隊伍整欄發光、中間有指向它的箭頭。

能動手的人在待分隊上方有一個「抽籤台」（別人看不到）：輪到的隊長（不輪流時兩位隊長都可以）和主辦。抽籤台有「抽一位」，主辦另有「一鍵隨機分隊」（隊長沒有：它會把兩隊一起分完）；點一張卡會鎖定到抽籤台上，隊長按「確認選入」、主辦選「編入紅隊／藍隊」。抽一位時，燈在待分隊的卡片間跑、越跑越慢，停在抽中的人（亮起隊色、標「抽中」），一拍後飛進隊伍；一鍵隨機分隊時卡片一張接一張飛進兩隊。每張卡都沿著隊色雷射飛進隊伍、蓋上 ASSIGNED，所有正在看的人都同步看到。抽籤有音效（`lib/draft-sound.ts`，和預告片同一套語言）：燈跳時是高低交替的手鼓、抽中時先「鎖定」兩聲嗶再接預告片配樂裡 007 的結尾和弦（`public/assets/draft/lock.m4a`）、卡片飛進隊伍是咻一聲、落地蓋 ASSIGNED 是蓋章聲；面板標題列有音效開關（記在瀏覽器），瀏覽器規定要先點過頁面才會出聲，之前開關會顯示「點一下開啟音效」。隊長的抽一位進自己的隊；主辦的抽一位進人數較少的一隊（一樣多就隨機；隊長輪流選人時抽給輪到的那隊）。主辦擁有隊長的所有功能：任何時候都能把人編入任一隊、把任何隊員（隊長除外）放回、抽籤；隊長只能放回自己隊上的人。選人以資料庫交易寫入，不會兩個人同時選到同一個人。首頁的特務名單（AGENTS ON MISSION）只以頭像框的顏色區分隊伍、不寫字；本人的特務檔案會顯示自己的隊伍。

### 製作預告片

每個鏡頭由 `scripts/trailer/film/` 的 HTML／CSS／JS 合成（`FILM.seek(t)` 依時間擺好每一層），素材在 `scripts/trailer/film/assets/`，人物以兩位老闆照片為參考生成。所有切點寫在 `scripts/trailer/timeline.json`，畫面與配樂共用。

配樂用主辦提供的兩段錄音（`007.m4a`、`Mission.m4a`，不放進版控），由 `scripts/trailer/music.mjs` 鋪到畫面下——剪輯跟著音樂走：錄音保持原速，畫面每個切點都對在錄音量出來的拍子上（timeline 的 `music` 寫明每段取哪裡、放在哪裡）：
- **修復**：兩段都是音量很小的手機單聲道錄音，先去掉 007 開頭幾個「喀」聲（只處理 2 kHz 以上、不到 2 毫秒），再用 Mission 開頭的純底噪做頻譜維納降噪（決策導向估計、有增益下限，不會變水聲），底噪降約 18 dB；接著去低頻隆隆聲、壓 200 Hz 箱音、補一點清晰度與空氣感。
- **007**（升半音到 G 小調，和 Mission 同調，只變調不變速）：2.6 秒起鋪冷開場，樂團在槍響進來、片名卡隨和弦換卡；最後一張卡的重音（13.03 秒）雷射線點燃，重音後 0.8 秒的長和弦完整響完、在 13.87 秒下一句之前收住，殘響帶著尾音再延續約兩秒。
- **Mission**：從 8.6 秒的手鼓一口氣用到 42.94 秒，中間不停：手鼓在雷射線燃燒時從比原音小 8 dB 推到大 7 dB（約等於全團），前段以 007 的餘音為主——由弱漸強；貝斯（12.07 秒）進來就是導火線點燃，快剪落在過門與全團進來的拍子上，對決的雷射對撞、特技、片名、日期都落在重拍上；片名前音樂只「吸一口氣」（約 0.2 秒壓低，不停），片名起整段提高 3 dB；自毀倒數每兩拍一個數字；主旋律第二句唱完（42.8 秒）後，下一段開頭的兩下重擊「燈（42.90 秒）、燈（43.22 秒）」在倒數停在 1 時落下，音樂在第三下之前停下、殘響延續，第三下的位置換成自毀爆炸（音效在音樂停下後提高 6 dB）。
- **音效**：`render-score.mjs` 只合成畫面上發生的聲音（白點、槍聲、雷射線燃燒、導火線、打字、鎖定、對戰槍聲、翻滾、片名與日期與自毀的重擊、燒穿），不再有自己的旋律；`music.mjs` 把它混在音樂下，加一點立體聲殘響空間，過 glue compressor，再以限幅器母帶到 −11 LUFS。

需要 Chrome（`CHROME_PATH`，預設為 Windows 安裝路徑）與 ffmpeg（含 rubberband、afir；ffmpeg-static 即可）：

```sh
node scripts/trailer/render-score.mjs
FFMPEG_PATH=/path/to/ffmpeg node scripts/trailer/music.mjs --007 path/to/007.m4a --mission path/to/Mission.m4a
FFMPEG_PATH=/path/to/ffmpeg node scripts/trailer/render-film.mjs --ar 16x9 --audio .trailer-build/score.wav --crf 24
FFMPEG_PATH=/path/to/ffmpeg node scripts/trailer/render-film.mjs --ar 9x16 --audio .trailer-build/score.wav --crf 24
```

只換配樂、畫面沒變時，不必重新輸出影片：用 ffmpeg 把 `score.wav` 換進現有影片（`-c:v copy`）即可。

`render-film.mjs` 用多個無頭 Chrome 每格拍 8 個子畫面（180° 快門）合成動態模糊，加上高光暈光後與配樂合併。`node scripts/trailer/film-frames.mjs --ar 16x9 --times 10.5,22 --out frames` 可輸出單格靜照檢查。重新輸出影片後，請一併更新 `lib/opening-assets.ts` 影片網址的 `?v=`（避免瀏覽器沿用舊檔）與 `TRAILER_BURN_AT`（＝timeline 的 `burn`）；預告內容改版時，也把 `lib/opening-history.ts` 的 `OPENING_VERSION` 換掉，看過舊版的裝置才會再自動播一次新版。
